当前用哪个模型

四个用途可以各指一个模型。把关每条消息都要跑一次，建议挑便宜的；识图必须选支持图片输入的。

渠道与模型清单

一个渠道 = 一套「接口地址 + 密钥 + 模型清单」。可以从 DSH 一键导入它已经配好的渠道。

只有改过的项才会提交；改完立即生效（端口例外，要重启）。

表情库

群里有人发表情时它会自动收（用看图描述当标签）。也可以把一整个文件夹交给它，逐张看、逐张学。

—张（有标签的会按话题被挑出来发）

RVC 调音台（按需启动）

调唱歌换声用的音色、变调、索引/保护、试听和存桌面。它不吃模型内存，所以一直开着；9885 换声服务才是用时才拉起来的。

当前音色

决定它开口时是什么声音。左边是 Windows 自带音色（选一个就行）；右边是本地克隆引擎，靠一段参考音频把音色搬过来。

发一条真语音（验证接入）

试听只是合成给自己听；这里是真发到 QQ。填 QQ 号 = 私聊发给那个人（自己测最方便），填群号 = 发到群里。

音色档案（参考音频）

每段干净的人声都能当一个音色。点「用这个」= 切到它；CPU 上零样本克隆一句要几秒。

她的日记

记忆记的是“关于你的事”，日记写的是“她自己的一天”。每天过了设定时间会自动写一条；这里也可以手动让她现在写。

这些变化怎么看？

中线代表原有性格，左右表示后天表达倾向，不是好坏评分，也不是人格完成度。偏移最多为 ±25，微小变化还未必影响回复。

一致反馈至少跨 3 个不同日期才开始积累；同一人一天最多贡献一次。没有新强化时，习惯会慢慢淡化。熟悉度只影响相处方式，不改变家人身份。

长期记忆

只有模型认为"值得长期记住"的事才会写进来（群里约定、称呼习惯这类）。按重要性 × 时效排序后注入。

按人记账

记忆挂在 QQ 号上，不是挂在会话上——同一个人换群、换私聊，它认识的是同一个人。模型说“值得记”的事会同时进到对应那本账里。
